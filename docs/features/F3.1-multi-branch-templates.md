# F3.1 — Multi-branch templates and branch comparison

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-05)

## Opening a new branch from a template

Branch record page → **Branches** panel → **New branch from this one**. The Home page panel offers **Use as template** on every branch card. Only users who can create branches (administrators) see these buttons.

The modal (`kemBranchCloneModal`) shows what the template branch holds and asks for:

| Field              | Notes                                                                                                                                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Branch name        | Required                                                                                                                                                                                                    |
| Branch code        | Required, unique, stored in upper case (for example HYD-01)                                                                                                                                                 |
| Invoice prefix     | Required, unique, so the new branch has its own invoice numbers                                                                                                                                             |
| City, email, phone | Optional                                                                                                                                                                                                    |
| What to copy       | Rooms, branch prices, branch discounts, upcoming closures, classes and weekly patterns (each can be switched off, with counts)                                                                              |
| Classes start on   | Shown when classes are copied. The template's timetable is moved so its first class starts on this date (default: the template's first class start if it is in the future, otherwise the 1st of next month) |

`BranchTemplateService.cloneBranch` then creates, in one transaction (all or nothing), as the user:

| Copied                      | How                                                                                                                                                                                                                        |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Branch policies             | Tax rate, invoice due days, attendance threshold, cancellation notice, delivery modes, operating hours, state and country                                                                                                  |
| Rooms                       | Active rooms with type, capacity, equipment and meeting URL                                                                                                                                                                |
| Branch prices               | Active, current or future branch-specific prices (organisation-wide prices already apply to every branch)                                                                                                                  |
| Branch discounts            | Active, unexpired branch discounts with a new code `<CODE>-<BRANCH CODE>` (codes are unique); an existing code is skipped with a note; usage counts start at zero                                                          |
| Closures                    | Branch closures that have not ended (organisation-wide closures already apply)                                                                                                                                             |
| Classes and weekly patterns | Planned, Open, Full and In Progress classes, created as **Planned**, without teachers or learners, with the copied room, moved by whole weeks to the new start date; the branch name or code in the class name is replaced |

The result screen lists the counts and next steps (assign teachers, generate sessions, open the classes for enrolment), and **Open new branch** goes to the new branch. Opening the branch is logged (`BranchTemplateService`, INFO).

**Not copied:** staff assignments, learners, enrolments, invoices and payments, sessions (generated later from the copied weekly patterns).

## Branch comparison (`kemBranches`)

On the Home page (sidebar) and each Branch record page (the current branch is highlighted). `BranchTemplateService.overview` aggregates per branch with grouped queries, run as the user, so each person sees the branches and figures they can see:

| Figure                                     | Source                                                                                |
| ------------------------------------------ | ------------------------------------------------------------------------------------- |
| Seats filled                               | Seats taken ÷ capacity of Open, Full and In Progress classes (bar turns amber at 90%) |
| Classes                                    | Running classes, plus planned ones                                                    |
| Learners                                   | Distinct learners with an Enrolled or On Hold enrolment                               |
| Attendance (30 days)                       | Present + Late ÷ Present + Late + Absent (red under 80%)                              |
| Waiting                                    | Learners on class waitlists                                                           |
| Open enquiries, rooms                      | Unconverted, qualified enquiries; active rooms                                        |
| Outstanding, overdue, collected this month | Finance users and administrators only (overdue in red)                                |

Totals across branches are shown on top (attendance weighted by seats taken). Cards can be sorted by name, fill rate, attendance, learners or outstanding fees. Users without access to the panel's Apex controller (for example teachers) do not see it.

## Access

- `BranchController`: administrators and branch managers.
- Opening branches requires create access on Branch (administrators only); branch managers see the comparison but not the template buttons.
- Administrators have edit access to every class and enrolment through the **KEM Administrators** group (owner sharing rules; the Education Cloud licence does not allow Modify All on these objects), so they can complete and open the copied classes regardless of owner.

## Tests

- Apex `BranchTemplateServiceTest`: preview counts (current prices and upcoming closures only, running classes only); full clone (policies, rooms, prices, renamed discount codes, closures, Planned classes with mapped room, no teacher, class and pattern dates moved by whole weeks); whole-week shift rules; partial clone with an existing discount code and no rooms; validation (template, name, code, prefix, duplicate code, duplicate prefix, start date) with nothing created; branch managers refused; overview figures and totals; class renaming.
- Jest `kemBranches` (totals, cards, warnings, sorting, current branch, clone and cancel, hidden finance and buttons, empty and error states) and `kemBranchCloneModal` (preview, validation, request, result and notes, start date hidden without classes, server error, no permission, load error).
