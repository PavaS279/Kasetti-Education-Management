# F1.8 — Basic assessments

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-03)

## What it does

| Capability    | How                                                                                                                                                                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Assessments   | `Course_Assessment__c` per class: type, maximum score, weight, date, grade scale; Draft → Published                                                                                      |
| Results       | `Assessment_Result__c` (master-detail): one per assessment + learner (`Unique_Key__c`, upsert); score 0..maximum, absent flag, feedback                                                  |
| Gradebook     | `AssessmentService.getGradebook`: learners with an active or completed enrolment (plus anyone already scored) and their draft results                                                    |
| Who may enter | The class teacher, or anyone who can edit the assessment (academic coordinator, branch manager, administrator). Writes run without sharing after that check (teachers read classes only) |
| Grading       | `Grade_Band__mdt` (configurable scales, read from the metadata cache). Publishing fixes each grade (absent → `ABS`), stamps publisher/date and the class average                         |
| Locking       | Published results cannot be changed (service rule; fields are system-managed)                                                                                                            |
| Learner view  | `AssessmentService.publishedResults` — only **published** results; used by Learner 360 and (F1.11) the portal                                                                            |

## User interface

- **Assessment record page** (`KEM_Assessment_Record_Page`, app override) with **`kemGradebook`**: hero with type/date/maximum/weight/status and live statistics (entered, average, highest, lowest); per learner score input with range validation, progress bar, live provisional grade bubble (colour by band), absent toggle, feedback; sticky bar with _Save draft_ and _Publish results_ (confirmation, saves unsaved changes first). Read-only notice once published or for users who cannot enter results. Responsive down to phone width.
- **Class record page**: **`kemClassAssessments`** lists the class's assessments with status and average and a **New** button that opens the standard create form pre-filled with the class and the Standard scale.
- **Learner 360**: new **Results** tab with assessment, class, score, percentage, grade badge and feedback.
