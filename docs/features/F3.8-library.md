# F3.8 — Library and resources

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-06)

Each branch lends books, devices, kits and media to its learners. Branch page → **Library** (`kemLibraryDesk`).

## Catalogue (`Library_Item__c`)

Title, unique item code (barcode), type, author/maker, subject, branch, shelf/location, copies, copies on loan (maintained by the service), available (formula), loan days, daily fine, replacement cost, active. **Add item** on the desk (administrators, branch managers, academic coordinators); search by title, code, author or subject.

## Loans (`Library_Loan__c`, LN-000001)

| Action | Rules                                                                                                                                                         |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Issue  | Active item with a free copy, to a learner of the branch (search by name) who has no overdue loan; due after the item's loan days or `Library_Loan_Days` (14) |
| Renew  | Before the due date, at most `Library_Max_Renewals` (2) times; extends by the loan days                                                                       |
| Return | Good or damaged; late returns fined per day (item daily fine or `Library_Daily_Fine`, 5), capped at `Library_Max_Fine` (500)                                  |
| Lost   | Replacement cost plus any late fine; the copy leaves stock (an item with no copies left becomes inactive)                                                     |
| Fines  | **Paid** (collected at the desk) or **Waive**; noted with who and when                                                                                        |

Copy counts are updated under a record lock, so two desks cannot lend the last copy twice. Lending needs create access on loans (administrators, branch managers, academic coordinators); teachers see the desk read-only.

**Daily job KEM Library (07:15):** loans past their due date become **Overdue**; on days 1, 7 and 14 the fee payer receives **Library_Overdue** (portal and email).

**Portal:** a **Library** tab lists each learner's loans (current and the last year) with due dates, days overdue and late fees due.
