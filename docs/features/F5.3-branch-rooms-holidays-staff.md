# F5.3 — New branch, rooms, holidays and Add staff member

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-07)

Phase 5 stage 2. These are the screens for setting up a centre and its people, all opened from the **Set-up Centre** on Home (F5.1).

## New branch (`kemBranchWizardModal`, administrators)

Five steps; nothing is saved until **Open the branch**, and then everything is saved together or not at all.

1. **Branch:** name, branch code and invoice prefix (the prefix follows the code, so JPN-01 gives JPN, until it is typed), branch manager (people with the branch manager or administrator persona, or "choose later"), phone and email.
2. **Policies:**
   - Address, including a 6-digit PIN code check (Bengaluru, Karnataka and India pre-filled).
   - Opening hours.
   - Delivery: classroom, online, hybrid.
   - GST (18%), payment terms (10 days), attendance minimum (75%) and cancellation notice (24 hours).
3. **Rooms:** name, type, seats, and equipment or, for a virtual room, a meeting link. A running count of rooms and seats is shown.
4. **Holidays:** the year's suggested list, ticked and editable (see below), with the year to suggest from (this year or next).
5. **Check and open:** a summary of the branch, invoice numbering (JPN-000001), manager, address, policies, rooms and holidays, with a reminder when there is no manager yet.

The server refuses a code, invoice prefix or name already used, and a tax or attendance percentage outside 0–100. The new branch opens afterwards, and its manager can edit its policies through manager sharing.

## Add rooms (`kemRoomModal`; administrators, branch managers, coordinators)

- Choose a branch (chosen already if there is only one), then add one or more rooms.
- Every room needs its seats, and a virtual room needs its meeting link (the existing rules on rooms).
- A name the branch already uses is refused, ignoring capitals.

## Add holidays (`kemHolidayModal`; administrators, branch managers, coordinators)

- Tick the branches (all of them by default, or the branch the screen was opened for).
- Add one closure, or press **Suggest the year's holidays** and adjust the list.
- **The suggested list** (`SiteSetupService.suggestedHolidays`):
  - Fixed-date holidays: Republic Day, May Day, Independence Day, Gandhi Jayanti, Kannada Rajyotsava, Christmas, and the Christmas–New Year break.
  - Festival dates for 2026 and 2027: Makara Sankranti, Ugadi, Good Friday, Ganesh Chaturthi, the Dussehra break and the Deepavali break. These are marked **Check date**, to be checked against the Karnataka government list, because they follow the lunar calendar. Changing a date clears the mark.
  - Past dates are shown as **Past** and left unticked.
- The button says what will happen, for example "Add 6 to 3 branches".
- A holiday a branch already has (same name and first day) is skipped, so a list can be applied again safely.
- No sessions are created on these days (F1.6).

## Add staff member (`kemStaffModal`, administrators)

This is the one screen that creates Salesforce logins. Each login uses a licence, so it is limited to administrators. A person needs both:

- the new **KEM Manage Staff** custom permission (in KEM Administrator), and
- Salesforce's **Manage Users** permission (System Administrators).

| Part          | What it does                                                                                                                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Licences      | Shows the free Salesforce and Education Cloud licences; adding is blocked when either is 0                                                                                                                    |
| Person        | First and last name, work email (the welcome email goes here), mobile                                                                                                                                         |
| What they do  | Teacher, academic coordinator, admissions counsellor, finance, branch manager, administrator. Each is a persona permission set group, and an administrator gets a warning that they see and change everything |
| Einstein      | Optional **KEM AI User** (AI drafts and summaries; Phase 4 controls apply)                                                                                                                                    |
| Welcome email | "Send the welcome email now" (on by default) sends Salesforce's email with the link to set a password                                                                                                         |
| Username      | Suggested as email + `.kasettitechnologiespvtltd` (unique across Salesforce) and can be edited                                                                                                                |
| Branch roles  | One or more branch and role lines; the role follows what the person does                                                                                                                                      |

**How the login is set up:** profile _EDC Staff User_, Indian locale, Asia/Kolkata time zone, the Education Cloud licence and its standard permission set, the persona group, and optionally KEM AI User. This is exactly how the existing staff are set up.

**Saving in two steps:** Salesforce does not allow users and branch roles in one transaction, so the screen saves the login first and then the roles. If the roles fail, the login is kept and the screen offers **Save the branch roles** again.

**Refusals:**

- No free licence.
- An invalid email or username, or a username that is already used.
- An active staff login with the same email.
- A persona that is not offered, such as the integration user.

## Manage staff (`kemStaffDirectoryModal`, administrators)

- Lists everyone with a KTEdutech persona: name, active or inactive, what they do, email, last login, and their branch roles as chips.
- Search by name, email or branch.
- **Add role** opens an inline branch and role picker. A role that was ended before is reactivated rather than duplicated.
- **×** on a chip ends that role after a confirmation. The role is kept in the history, and the person keeps their login and other roles.
- Deactivating a login stays in Salesforce Setup (Users).

## Set-up Centre changes

- **New** on Branches, Rooms and Holidays opens these screens for people who may create those records.
- Staff roles:
  - People who can manage staff see **Add staff member** and **Manage staff**.
  - Everyone else who may add roles, such as branch managers, keeps the standard Branch Staff form.
