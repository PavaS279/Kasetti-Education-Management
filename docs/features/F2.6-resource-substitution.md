# F2.6 — Resource substitution: teacher cover and room swaps

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-05)

## Data model

| Item                           | Purpose                                                                                                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Staff_Absence__c` (ABS-00001) | Teacher, branch, from/until, reason (Sick Leave, Planned Leave, Training, Personal, Other), notes, reported by; status Needs Cover → Partially Covered → Covered, or Withdrawn; sessions affected and handled |
| `Class_Session__c` new fields  | Needs Cover, Staff Absence, Original Teacher, Original Room, Cover Note (all system-managed); activities enabled so the cover teacher gets a task on the session                                              |
| Permissions                    | Teachers can report their own absence (create); schedulers (edit access to a session's teacher and room: administrators, branch managers, academic coordinators) arrange cover and change rooms               |

## Behaviour

| Step             | Rule                                                                                                                                                                                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report absence   | Own absence, or any teacher's for schedulers; no overlapping open absence. Every **scheduled** session of the teacher in the period is flagged **Needs Cover** and linked to the absence                                                                                           |
| Suggestions      | Active teachers on the session branch's staff list (role Teacher), excluding the absent teacher, ranked: **free** at that time (not teaching, not absent) → **has taught the course** → **fewest sessions that day** → name. Busy teachers show why ("Teaching ‹class›", "Absent") |
| Assign cover     | Session teacher becomes the cover teacher (the trigger's double-booking check applies), Original Teacher kept, teacher attendance **Substituted**, optional note, a high-priority **task** for the cover teacher; assigning the original teacher back clears the substitution      |
| Cancel instead   | The session is cancelled with the reason and **families are notified** (F2.5 Session_Cancelled)                                                                                                                                                                                    |
| Absence progress | Sessions handled (covered or cancelled) / affected; status follows                                                                                                                                                                                                                 |
| Withdraw absence | Sessions still waiting go back to the teacher; covered sessions stay covered                                                                                                                                                                                                       |
| Room swap        | Active rooms of the same branch, **free and large enough** first (capacity ≥ enrolled learners); too small or double-booked rooms are refused; Original Room kept; moving back clears it                                                                                           |

## User interface

The org has reached its custom tab limit, so the cover desk lives on the Kasetti home page:

- **Cover Desk** (`kemCoverDesk`, home page): sessions needing cover with up to four ranked teachers (free/has taught/load, or why they are busy) and **Assign**, **Cancel** per session; absences with a handled bar, status and **Withdraw**; **Report absence** (`kemAbsenceModal`: teacher for schedulers, from, until, reason, notes); an all-clear state. Teachers see it read-only and can report their own absence.
- **Teacher and room** (`kemSessionCover`, session record page): current teacher and room with "covering for" / "moved from", a needs-cover alert, **Find cover / Change teacher** and **Change room** pickers with the same suggestions and an optional note. Hidden from users who cannot edit the session's teacher and room.

## Tests

- Apex `CoverServiceTest`: a teacher reports their own absence (not others', and cannot arrange cover); two sessions flagged; overlapping absence refused; desk ranking (free teacher who taught the course first, busy teacher with the clash); double-booked cover refused by the trigger; cover assigned (original kept, Substituted, task); cancellation; Partially Covered → Covered; withdrawal (released sessions); room options (booked R2, too-small R3), swap refused for capacity and double booking, swap and swap back; validation and controller errors; sorting by load.
- Jest: `kemCoverDesk`, `kemAbsenceModal`, `kemSessionCover`.
