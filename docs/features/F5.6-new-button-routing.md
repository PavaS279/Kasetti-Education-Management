# F5.6 — Standard New buttons open the guided screens

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ Checked in the org (2026-10-07)

Phase 5 stage 6. Pressing **New** anywhere in the app now opens the KTEdutech guided screen instead of Salesforce's standard form, for these objects:

- Branches, Rooms, Courses and Classes: from a list view, the object's tab, or a related list.
- People (Account).

Administrators keep the standard form as a fallback, as decided on 7 Oct 2026.

## What happens when someone presses New

| Object                                                     | Guided screen                                                             | Who gets it                                                                                                    |
| ---------------------------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Branch                                                     | New branch (F5.3)                                                         | Anyone who may create branches (administrators)                                                                |
| Room                                                       | Add rooms (F5.3); the branch is filled in from a branch's Rooms list      | Administrators, branch managers, coordinators                                                                  |
| Course (Learning Course)                                   | New course (F5.2), optionally followed by New class                       | Administrators, coordinators                                                                                   |
| Class (Course Offering)                                    | New class (F5.2); the course or branch is filled in from its related list | Administrators, coordinators. Branch managers keep the standard form (no access to weekly patterns or courses) |
| Account, _Person Account_ record type                      | New family (F5.4)                                                         | Administrators, branch managers, counsellors                                                                   |
| Account, other record types (business, household, school…) | Standard form                                                             | Everyone                                                                                                       |

**Who sees what:**

- **Staff** go straight to the guided screen.
- **Administrators** (System Administrators, or the KEM Administrator persona) see a short choice first: **Guided screen (recommended)**, **Standard form** or **Cancel**.
- **Anyone who cannot complete the guided screen** goes to the standard form. This also covers record types that have no guided screen.

**Afterwards:**

- Saving opens the new record: the branch, course, class or first child.
- Cancelling goes back to the record the button was pressed from, or to the object's list.

The standard form opens with `nooverride=1`, so it never loops back to the guided screen. The record type and default values are kept. A bookmark such as `/lightning/o/Room__c/new?nooverride=1` always opens the standard form.

## How it is built

- **Aura `kemNewOverride`:** Salesforce accepts only Aura components as button overrides, so this thin Aura component (`lightning:actionOverride`) passes the page reference to the LWC `kemNewRouter`.
- **LWC `kemNewRouter`:**
  - Reads the object, the record type, the record the New button was pressed from (`inContextOfRef`) and any default values.
  - Asks `NewRouterController.getContext` which guided screen applies and whether the user is an administrator.
  - Opens the matching modal, and navigates to the new record afterwards.
- **`NewRouterController`:**
  - Decides from the person's create permissions. These match the persona permission sets that give the screens' controllers.
  - Uses KTEdutech names for the Education Cloud objects (Course, Class).
  - Is in all six staff permission sets.
- **Overrides:** desktop (Large form factor) only. The phone keeps the standard form.
  - Branch and Room: set through the generator (`newOverride` in `scripts/tooling/specs.py`).
  - Account, Learning Course and Course Offering: the object definitions were retrieved from the org and redeployed with only the New override changed. Child components such as fields and list views were left out, so they are untouched.
