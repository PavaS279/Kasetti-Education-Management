# F1.7 — Attendance

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-03)

## What it does

| Capability         | How                                                                                                                                                                                      |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Learner attendance | `Session_Attendance__c` (master-detail to session): Present, Late (+ minutes), Absent, Excused, note; one row per session + learner (`Unique_Key__c`, upsert)                            |
| Register           | `AttendanceService.getRegister`: learners whose enrolment is active on the session date (plus anyone already marked) with their current attendance rate                                  |
| Who may mark       | The session's teacher, or anyone who can edit the session (academic coordinator, branch manager, administrator); from one hour before start; never for cancelled sessions                |
| Corrections        | Changing a saved mark sets `Corrected__c` and keeps `Previous_Status__c`, `Marked_By__c`, `Marked_At__c` (field history on status)                                                       |
| Teacher attendance | `Class_Session__c.Teacher_Attendance__c` (Present, Late, Absent, Substituted); saving the register marks the session **Completed** and `Attendance_Marked__c`                            |
| Statistics         | Per enrolment: `Sessions_Attended__c` (Present + Late), `Sessions_Missed__c`, `Attendance_Rate__c`; Excused and cancelled sessions are not counted                                       |
| Threshold alert    | Branch threshold (or org default 75%) → `Below_Attendance_Threshold__c`; on first crossing, a high-priority follow-up task for the branch manager (or the teacher) linked to the learner |

## User interface

- **Session record page** (`KEM_Session_Record_Page`) with **`kemAttendanceRegister`**: hero with live counters (Present / Late / Absent / Excused / Unmarked), _Mark all present_, per-learner segmented P/L/A/E buttons (`aria-pressed`, keyboard focus), minutes-late input, note, each learner's current rate (red when below threshold), sticky save bar with teacher attendance, _Save corrections_ when already marked; read-only notice for users who cannot mark. Single-column on phones.
- Timetable drawer: **Attendance** button opens the session register.
