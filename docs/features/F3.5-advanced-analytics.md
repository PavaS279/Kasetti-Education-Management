# F3.5 — Advanced analytics

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-06)

Home page (top, under the insights) and each Branch page → **Analytics** (`kemAnalytics`), for administrators, branch managers, academic coordinators and finance. Filters: branch (all or one; the branch page opens on its branch) and period (6, 12 or 24 months). **Show as table** gives the same monthly figures as a table.

| Section                      | Content                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Tiles                        | Invoiced, collected, collection rate; new enrolments, withdrawals, retention of the last six cohorts         |
| Invoiced and collected       | Paired monthly bars (blue invoiced, orange collected) with hover details                                     |
| Enrolment flow               | New enrolments and withdrawals per month                                                                     |
| Attendance rate              | Monthly line (present + late ÷ marked)                                                                       |
| Retention by enrolment month | Each of the last six months' enrolments still enrolled, on hold or completed, shaded from light to deep blue |
| Receivables ageing           | Open balance not yet due, 1–30, 31–60, 61–90 and over 90 days overdue, with invoice counts                   |
| Courses                      | Running classes per course, seats filled, average course score                                               |

- `AnalyticsService` uses aggregate queries only, run as the user: each person sees only records they can see, and sections they cannot read (finance for teachers and coordinators without invoice access) are left out.
- Charts are SVG drawn by the component (no external libraries); the two series colours are a validated colour-blind-safe pair; every series has a legend, hover tooltips and a table view.

## Tests

- Apex `AnalyticsServiceTest`: a branch with two enrolments, one invoice 1,180 part-paid 590 and one withdrawal → 1,180 invoiced, 590 collected (50%), 2 new, 1 withdrawn, cohort retention 50%, 590 outstanding in ageing, course row; teachers get the default 12 months without finance.
- Jest `kemAnalytics`: tiles, charts, cohort shading, ageing, courses; tooltips on hover for all three charts; table view and filter reloads; finance hidden; hidden without access.
