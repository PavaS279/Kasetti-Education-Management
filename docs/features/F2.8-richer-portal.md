# F2.8 — Richer portal

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-05)

The family portal (`kemPortalHome` on `/s/my-learning`) now shows the Phase 2 features. Everything is read through `PortalService` in system mode after the existing authorisation check: the viewer themselves (as a learner) and learners they are an active guardian of **with portal access**.

| Area          | What families see                                                                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inbox**     | "Messages (n new)" in the header: the viewer's own portal messages (F2.5 notifications and staff messages), newest first; opening one shows the full text and marks it read (`Read_On__c`); only the recipient can mark it read |
| **Grades**    | Results tab starts with course grades per class (F2.7): grade, score, Final or "Provisional — may change", and a **Report card** download once final                                                                            |
| **Documents** | New tab: current invoice, receipt and report card PDFs (superseded report cards hidden), with **Download**                                                                                                                      |
| **Fees**      | Invoice billing period (F2.3), the instalment schedule with paid and overdue steps, and any open credit ("used on your next invoice automatically", F2.4)                                                                       |
| **Waitlist**  | Timetable tab starts with waitlist entries (F2.1): "Number n on the waiting list", or a held seat with the time it expires                                                                                                      |

**Downloads:** portal users cannot open files linked to staff records, so `downloadDocument` returns the PDF as base64 after checking that the file is one of the viewer's authorised learners' current documents (invoice, receipt of a confirmed payment, report card of an enrolment). Anything else: "Document not found or not available to you."
