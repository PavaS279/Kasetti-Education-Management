# F5.1 — Set-up Centre

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-07)

Phase 5 gives every set-up record its own KTEdutech screen. The Set-up Centre is the starting point: one card on the **Home** page (`kemSetupCentre`, below the greeting) for administrators, branch managers and academic coordinators. Everyone else does not see it.

## Tiles

| Tile          | Count                       | Detail                | Actions                              |
| ------------- | --------------------------- | --------------------- | ------------------------------------ |
| Branches      | Active branches             | Inactive ones, if any | New branch · View all                |
| Rooms         | Active rooms                | Total seats           | New room · View all                  |
| Staff roles   | Active branch roles         | Number of people      | Add staff role · View all            |
| Courses       | Active courses              | —                     | New course                           |
| Classes       | Planned and running classes | Running · planned     | New class                            |
| Holidays      | Closures today or later     | The next one          | New holiday · View all               |
| Discounts     | Active codes still valid    | —                     | New discount · View all              |
| Faculty       | Teachers on current classes | —                     | (form arrives with the class wizard) |
| Portal access | Active family logins        | Free portal licences  | (button arrives in stage 4)          |

**New** appears only where the person may create that record (for example branch managers do not create branches). It opens the record form today; the guided screens of the next stages replace it tile by tile. **View all** opens the list ("All" view where one exists).

## Set-up gaps

Problems that stop the timetable, billing or the portal from working, each with the first five records (links) and the count of the rest:

| Gap                                       | Why it matters                                                        |
| ----------------------------------------- | --------------------------------------------------------------------- |
| Branches without rooms                    | Classes and exams cannot be seated                                    |
| Branches without a branch manager         | Nobody approves refunds or sees the branch desks                      |
| Courses without a tuition price           | Enrolments would be free                                              |
| Classes without a teacher                 | Registers, cover and "My sessions" need one (teacher user or faculty) |
| Classes without a branch                  | Prices, invoices and branch desks depend on it                        |
| Classroom classes without a room          | No clash or capacity checks                                           |
| Classes without a seat limit              | The class can never be full or have a waitlist                        |
| Running classes with no upcoming sessions | Add a weekly pattern and generate sessions, or close the class        |

Gaps with nothing to fix are hidden; the header shows "n to fix" or "All set".

## Access

Counts and gaps run in user mode, so each person sees what they can see. The card is shown to people who can create rooms, branches or classes (administrators, branch managers, academic coordinators); `SetupCentreController` is in those three permission sets.

## Tests
