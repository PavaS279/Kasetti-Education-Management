# F2.7 — Advanced grading: weighted course grades and report cards

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-05)

## Course grade

`GradingService` calculates a **course score** for every enrolment (Enrolled, On Hold, Completed) from the class's **published** assessments:

| Rule           | Behaviour                                                                                                                                                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Weights        | Assessment `Weight__c`. If no assessment has a weight, all count equally; once any has a weight, unweighted ones do not count. Shown as "% of grade"                                                              |
| Per assessment | Score ÷ max × 100                                                                                                                                                                                                 |
| Absent         | Counts as 0% (Education Setting `Absent_Counts_As_Zero` = true), or is left out (false)                                                                                                                           |
| Not marked     | Left out; the other weights are rescaled                                                                                                                                                                          |
| Grade          | From the class's grade scale (`Grade_Band__mdt`; the first scale named on its assessments, else Standard)                                                                                                         |
| When           | Recalculated automatically whenever an assessment is published, and when weights change; stored on the enrolment (`Course_Score__c`, `Course_Grade__c`, `Graded_Assessments__c`, `Grade_Status__c` = Provisional) |

## Finalising and report cards

- **Finalise** (class teacher, anyone with edit access to the class, or users with Modify All on assessments — administrators and academic coordinators): every assessment must be published. Grades are locked (`Grade_Status__c` = Final, class `Grading_Status__c` = Final with who and when), a **report card PDF** is issued per learner in the background and filed on the enrolment, and each fee payer gets a **Report_Card_Ready** message (F2.5).
- **Report card** (`KEM_Report_Card`): learner, course, class, teacher, period, attendance, course grade and score (or PROVISIONAL), each assessment with date, weight share, result, %, grade and feedback, the teacher's comment, the grade scale, signature line.
- **Comments:** teachers write a report card comment per learner (`Report_Comment__c`).
- **Reopen** (administrators and coordinators, with a reason): grades become provisional, and issued report cards are kept but marked **superseded** (with the reason) so finalising again issues new ones.
- Teachers and academic coordinators now have access to the document pages, because report cards render as the user who finalises.

## User interface

Class record page → **Course grades** (`kemClassGrades`): status (Provisional/Final, who and when), scale, class average; a grid of learners × assessments (%, grade, Absent) with sticky learner names, weight inputs and "% of grade" per assessment, score, colour-coded grade, attendance and an editable comment per learner; **Save weights**, **Save comments**, **Finalise & issue report cards** (confirmation), **Reopen** (reason); report card links once final; a warning while draft assessments exist.

## Tests

- Apex `GradingServiceTest`: provisional grades on publish (80 → A; absent counts as zero → 36.67 F; unmarked exam left out → 80), absence left out when configured (55); teacher sets weights (shares 60/30/10; 75 → B; 85 → A) and comments; finalising as the teacher (report card job, notices, class status, locked comments, report card content); reopening (reason required, superseded document kept for history, provisional preview, draft assessment blocks finalising); guards (other teacher refused, weight range, foreign assessment/enrolment, unknown class, reopen when not final).
- Jest `kemClassGrades`: grid, weights and comments saved, finalise with confirmation, final state and reopen, draft warning and empty class.
