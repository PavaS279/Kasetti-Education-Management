# F1.2 — Learner & guardian records, Learner 360

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-03)

## What it does

| Capability                            | How                                                                                                                                                                                                                        |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Learner profile & student number      | `AccountTriggerHandler` → `LearnerService.ensureProfiles`: every person account with role Learner (or Learner and Guardian) gets one `LearnerProfile` with auto-numbered `Student_Number__c` (`STU-00001`) and home branch |
| Multiple guardians, multiple children | `ContactContactRelation` (Guardian ↔ Child); a guardian can link to several learners, a learner can have several guardians                                                                                                 |
| Separate payer / guardian / learner   | Fee payer, portal access, and emergency contact are flags **per relationship**, not per person                                                                                                                             |
| Add guardian                          | Link an existing person (search by name, email, mobile) or create a new one; matching email/mobile re-uses the existing person (no duplicates)                                                                             |
| Edit / end relationship               | Edit flags and relationship type; _End relationship_ keeps history (inactive, end date) and revokes portal access and fee-payer status through that link                                                                   |
| Siblings                              | Learners who share an active guardian                                                                                                                                                                                      |
| Communication preferences             | `Preferred_Channel__c`, `Preferred_Language__c`, SMS/WhatsApp opt-ins, email opt-out, `Emergency_Instructions__c` on the person contact                                                                                    |
| Learner history                       | Applications and class enrolments in one view (attendance, results, and finance tabs are added by later features)                                                                                                          |

## User interface

`KEM_Learner_Record_Page` (Account record page in the Kasetti Education app) with **`kemLearner360`**:

- Hero: avatar, name, student number, role chips, home branch, KPIs (guardians, applications, active classes), contact line.
- Emergency instructions alert.
- Tabs: **Overview** (guardian cards with flag badges and edit/end menu, siblings, children for guardians), **Applications**, **Classes**, **Preferences** (editable form).
- **`kemGuardianModal`**: new or existing person, live search, relationship, fee payer / portal / emergency toggles.
