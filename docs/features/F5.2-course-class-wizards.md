# F5.2 — New course, New class and faculty screens

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-07)

Phase 5 stage 3. Courses and classes are the set-up records created most often, so they have guided screens first. All three open from the **Set-up Centre** on Home (F5.1).

## New course (`kemCourseWizardModal`)

One screen creates the Education Cloud _Learning_ record, the course and its prices together. If any part fails, nothing is saved.

| Section | Fields                                                                                                                                                                                                                                                                  |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Course  | Name (required, unique), code (optional, unique, upper-cased, for example `KT-CRS-CHS`), minimum and maximum age, description                                                                                                                                           |
| Prices  | "Prices from" date (today by default) and one line per fee: fee type (Tuition, Admission, Kit and materials, Assessment, Other), how often (Monthly, Per term, One-time), amount, branch (all branches, or one branch to override). Lines without an amount are skipped |

- The screen opens with two lines, monthly tuition and one-time admission.
- It warns if there is no tuition amount, because enrolments would then be free.
- Prices show only to people who may create them (administrators and finance). An academic coordinator creates the course, and finance adds the prices later.
- **Create and add a class** goes straight into New class with the course already chosen.

## New class (`kemClassWizardModal`)

Four steps along a path at the top of the screen:

1. **Class:** course, branch, delivery (Classroom, Online, Hybrid), seats, an optional name, an optional section code, and "Open for enrolment now" (otherwise _Planned_). An empty name becomes "Course – Saturday 10:00".
2. **Room and teacher:**
   - The room list shows the branch's rooms with their seats. A room smaller than the class is stopped before the next step.
   - The teacher list (the login used for registers and marks) shows the branch's staff with the Teacher role.
   - "Faculty shown to families" lists the faculty, and **New faculty member** adds one without leaving the screen.
   - Hints appear when the branch has no rooms or no teachers yet, and when a class is online and needs no room.
3. **Timetable:** first and last day (today and 90 days later by default), then one or more weekly times. Each weekly time has day chips (Mon–Sun), a start time and a length (45 minutes to 3 hours).
4. **Check and create:** a preview, with nothing saved yet:
   - The number of sessions.
   - Sessions skipped for branch holidays.
   - Clashing sessions, with the room or teacher already booked.
   - The first four sessions and the last one.
   - Points worth checking, such as no room, no teacher, a teacher who is not a teacher at the branch, or a course without a tuition price.

**How the preview works:** it runs the real session generation (`SessionService.generate`) inside a transaction and then rolls everything back. What it shows is therefore exactly what **Create class** will produce.

**Clashes:**

- A clashing session is not created. The button then reads **Create without the clashing sessions**, so it is clear that only the other sessions will be made.
- If no session can be created (every one clashes, or none fall within the dates), creating is blocked on the screen and refused on the server.

After creating, the class opens and a message gives the number of sessions added.

## Faculty (`kemFacultyModal`)

- Faculty are the teachers named on classes, timetables, the portal and report cards. They need no Salesforce licence.
- They are contacts of the institution's faculty account, _KT Edutech Faculty_. The account is created on first use and named "<Institution_Name> Faculty".
- The form takes the first and last name, email (checked for duplicates), phone and subject. The title becomes "Faculty – Robotics", for example.
- To give a teacher a login, add them as a staff member instead (stage 2).

## Set-up Centre changes

- Each tile now says whether **New** opens a guided screen (`wizard`).
  - Courses: the person can create Learning and course records.
  - Classes: the person can create classes and weekly patterns, and read courses.
  - Faculty: the person can create contacts and classes.
- Otherwise **New** still opens the standard record form. Branch managers, for example, keep the standard class form, because weekly patterns and courses are not in their permission set.
- **View all** on Faculty opens the faculty account, not every contact.

## Access

`CatalogSetupController` is in the **KEM Administrator** and **KEM Academic Coordinator** permission sets. Everything runs in user mode, so a person can only create what their permission sets allow. Two exceptions run in system mode, and neither exposes data:

- Duplicate checks, which look at course codes, course names and faculty emails across the institution.
- Creating the faculty account itself.

Teachers are refused.

**Live as the administrator on the KT Edutech data.** Each check ran in a transaction that was rolled back, so nothing was left in the org.

- **Tiles:** the Courses, Classes and Faculty tiles open the screens. Faculty lists the _KT Edutech Faculty_ account.
- **Choices:** 40 courses, 7 branches, 8 faculty. Indiranagar shows 3 rooms with their seats and 2 teachers.
- **Clashing preview:** _Python for Kids_ at Indiranagar, Turing Lab, Saturday 12:00, 10 Oct–19 Dec, showed 0 sessions, 1 holiday (Christmas break) and **10 clashes** ("The room is already booked for Python for Kids – Saturday 12:00"). No class was saved.
- **Free slot:** the same class at 15:30 showed 10 sessions, 0 clashes, and the warning "no teacher chosen".
- **Create, then roll back:** created course _Chess for Beginners_ (KT-CRS-CHS, ₹2,200 a month), its class _Chess for Beginners – Saturday 15:30_ (Open, 10 sessions) and faculty _Meera Pillai_ (Faculty – Chess, KT Edutech Faculty). Then rolled back.
- **Access:** administrators and Anjali Advisor (Academic Coordinator persona) have `CatalogSetupController`.

**Found and fixed:**

- **Clashing sessions:** session generation refuses each clashing session, so a class created "anyway" would silently lose those sessions. The wizard now names this, and refuses a class with no sessions.
- **Faculty account lookup:** the faculty account's external id field is not readable for staff, so the account is now found by name.
- **Weekly pattern end date:** a pattern's end date cannot be set in user mode, so patterns follow the class's last day.
