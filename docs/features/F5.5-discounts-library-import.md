# F5.5 — Discount screens and library bulk add and import

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-07)

Phase 5 stage 5 adds KTEdutech screens for discount codes and for putting a whole library catalogue in at once.

## Discounts (`kemDiscountManagerModal`, `kemDiscountModal`, shared `kemDiscountForm`)

**Where they open:**

- **Finance Desk → Discounts**.
- **Home → Set-up Centre**: Discounts **New discount** and **Manage discounts**.

**Manage discounts** lists every code. For each one:

- **Status:** _Active_, _Scheduled_ (starts later), _Expired_, _Used up_ (limit reached) or _Inactive_.
- **What it gives,** for example "10% off" or "₹1,000 off".
- **Where it applies:** the fee type, branch and course.
- **Dates.**
- **Use:** "12 used" or "2 of 20 used", the number of enrolments, the amount given so far, and how many uses are **waiting for approval**.

Switched-off codes are hidden until **Show switched-off codes** is ticked. **Edit** opens the form in place. **Switch off** and **Switch on** keep a used code for its history instead of deleting it.

**The form:**

| Field          | Notes                                                                                                                      |
| -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Code           | Upper-cased with spaces removed as it is typed (`diwali 15` becomes `DIWALI15`); 3–30 letters, numbers, `-` or `_`; unique |
| Kind, value    | Percentage (up to 100) or fixed amount (above zero); an example is shown, such as "On a ₹2,500 fee this gives ₹375 off"    |
| Applies to     | A fee type (Tuition by default), or any fee; one branch or all; one course or all                                          |
| From, until    | Optional; the last day cannot be before the first                                                                          |
| Uses allowed   | Empty means no limit; otherwise 1 or more                                                                                  |
| Needs approval | Finance approves each use (F1.4)                                                                                           |
| Active         | On by default                                                                                                              |

The server checks all of this again, as well as the rules already on discounts, and saves in user mode.

## Library catalogue import (`kemLibraryImportModal`) and Add copies

Both are on the branch's **Library** desk, in the **Catalogue** tab.

**Import:**

1. Choose a CSV file (up to 1 MB) or paste the lines; **Download a template** gives a sample file.
2. Columns, in any order and with any capitals:
   - **Title** and **Code** are required.
   - Optional: Type (Book, Device, Kit, Media, Other; Book if empty), Author, Subject, Copies (1 if empty), Location, Loan days, Daily fine, Replacement cost.
   - Also accepted: Name for Title, ISBN or Item code for Code, Quantity for Copies, Shelf for Location, Fine for Daily fine.
   - Quoted values, commas inside quotes, a byte-order mark and `₹` in amounts are handled.
3. **Preview** shows every line before anything is saved:
   - _New_.
   - _Add copies_, for a code the branch already has, for example "Wings of Fire: 3 → 5 copies".
   - _Error_, with the reason: no title, no code, a code repeated in the file, the wrong type, copies that are not a number, or copies outside 1–1000.
   - A summary line, for example "2 new · 1 with copies added · 5 copies in all · 1 skipped".
4. **Import n lines** saves the lines without errors together and skips the rest. Up to 500 lines can be imported at a time.

**Add copies** on any catalogue item adds 1–1000 copies of the same title as new stock. Loans and availability follow from the copy count.

## Set-up Centre and Finance Desk changes

- **Discounts tile:** **New discount** opens the form, and **Manage discounts** (for people who may change codes) opens the list.
- **Finance Desk:** a **Discounts** button in the header.
- **Library desk:** an **Import** button next to Add item, and **Add copies** on each item.
