# F1.4 — Course prices and discounts

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-03)

## What it does

| Capability           | How                                                                                                                                                                                                                                                       |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fee structures       | `Fee_Price__c`: fee type (Admission, Tuition, Materials, Assessment, Other), billing frequency (One-time, Monthly, Term), amount, effective-from/to, active flag, history tracking                                                                        |
| Pricing variations   | Optional branch and delivery-mode scope; resolution picks the most specific active price per fee type + frequency (branch beats global, then mode beats generic) on the quote date                                                                        |
| Price versioning     | Effective dates; overlapping active prices in the same scope are rejected (also within one batch); _End price_ closes the current version so a new one can follow                                                                                         |
| Discounts            | `Discount__c`: unique case-insensitive code, percentage or fixed amount, optional fee-type / course / branch scope, validity dates, max uses with usage counter, _requires approval_ flag                                                                 |
| Quote                | `PricingService.quote`: lines per resolved price, discount (percentage per eligible line; fixed amount spread across eligible lines up to its value), branch tax after discount, half-up rounding to 2 dp, warnings for missing prices and unusable codes |
| Historical integrity | Quotes reference `Fee_Price__c` IDs; the agreed amounts are copied onto enrolments and invoice lines in F1.5/F1.9 so later price changes never alter past charges                                                                                         |

## User interface

- **Course record page** (`KEM_Course_Record_Page`) with **`kemCoursePricing`**: price cards with Active / Scheduled / Ended state, scope chips and _End price_; _New price_ modal (`kemPriceModal`, record edit form); live **quote simulator** (branch, mode, date, discount code → debounced quote with line breakdown, totals, approval badge, warnings).
- Tabs: Fee Prices, Discounts, Learning Courses.

## Access

| ------------------------- | ----------------- | ----------------------------- | -------------------------------------------- |
| Fee_Price__c, Discount__c | Full + Modify All | Create/Edit/Delete + View All | Read                                         |
