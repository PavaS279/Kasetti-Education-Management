## Dashboard — **KEM Operations** (folder KEM Dashboards)

Dynamic dashboard (runs as the logged-in viewer, so nobody sees more than their own access allows): metric tiles for outstanding, collected and seats taken; admissions funnel; applications donut; seats by class status; attendance marks; balance due by invoice status; collections by method.

## Home page — **KEM Home Page** (KTEdutech app default) with **`kemInsights`**

Role-aware cockpit computed in user mode; each section appears only if the viewer can read the objects behind it:

- Greeting with date; buttons to the Timetable and the Operations dashboard.
- Alert pills: learners below the attendance threshold, payments needing reconciliation (opens Finance Desk), discounts awaiting the viewer's approval.
- **Today's classes** (teachers: their own; coordinators/managers: all visible) with _To mark / Marked / Cancelled_ badges; click opens the attendance register.
- Animated ring gauges: seats filled across active classes; attendance rate over the last 30 days.
- Receivables card: outstanding, overdue, collected this month (finance, managers, administrators).
- Admissions tiles: open enquiries (+ new this week), applications in review (+ ready for decision), offers awaiting reply.
