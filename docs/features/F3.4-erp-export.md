# F3.4 — Generic ERP finance export

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-06)

No ERP has been chosen yet, so finance leaves Salesforce as a **balanced double-entry journal** that any ERP (Tally, Zoho Books, SAP Business One, NetSuite, …) can import as CSV or read as JSON.

## Journal rules (`FinanceExportService`)

| Document                     | Date         | Debit                        | Credit                        |
| ---------------------------- | ------------ | ---------------------------- | ----------------------------- |
| Invoice issued               | Issue date   | Receivables (total)          | Revenue (net of tax), Tax     |
| Invoice cancelled            | Cancellation | Revenue, Tax                 | Receivables (entry IDs `-X-`) |
| Payment confirmed            | Payment date | Cash (cash payments) or Bank | Receivables                   |
| Credit applied to an invoice | Payment date | Customer credit              | Receivables                   |
| Credit note — overpayment    | Issue date   | Receivables                  | Customer credit               |
| Credit note — other origins  | Issue date   | Credits and allowances       | Customer credit               |
| Refund paid                  | Paid date    | Customer credit              | Bank                          |

- Account codes are Education Settings `ERP_Account_Receivable` (1100), `_Bank` (1010), `_Cash` (1000), `_Revenue` (4000), `_Tax` (2200), `_Customer_Credit` (2300), `_Credit_Allowance` (4900): map them to the ERP's chart of accounts without code changes.
- Each line: entry ID (document number + sequence), date, document type and number, branch code, account code and name, debit, credit, learner, payer, reference (gateway transaction or bank reference), description. Every document balances; the journal reports `balanced`.
- Ranges up to 92 days, optionally one branch. Void credit notes are left out.
- CSV values are quoted and text starting with `= + - @` is prefixed with `'` so spreadsheets cannot run it as a formula.
- Reads run as the user: finance users, administrators and the integration user only.

## Ways out

| Where                                                           | What                                                                                                                  |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Finance Desk → **ERP export**                                   | From/to, branch → **Preview** (account totals, balanced badge) → **Export CSV**; recent exports with **Download CSV** |
| Daily job **KEM Finance Export** (03:15)                        | Yesterday's journal, when `ERP_Daily_Export` is On                                                                    |
| `GET /kem/v1/erp/journal?from=&to=&branch=&format=csv           | json`                                                                                                                 | Journal on demand |
| `POST /kem/v1/erp/exports` `{ "fromDate", "toDate", "branch" }` | Creates an export record (run type API) with the CSV file                                                             |
| `GET /kem/v1/erp/exports`                                       | Latest 20 exports with file IDs                                                                                       |
| `GET /kem/v1/erp/events`, `POST /kem/v1/erp/events/ack`         | ERP outbox events (F3.3)                                                                                              |

Every export is a **Finance Export** record (EXP-000001: period, branch, run type, lines, documents, total debit/credit, file) with the CSV attached.

## Tests

- Apex `FinanceExportTest`: a full ledger day (invoice 1,180 with 18% tax, cash payment, withdrawal credit 200, UPI refund 200) gives balanced totals on every account; CSV header, one row per line, quoting; export record with linked file; cancellation reversal; validation (dates, order, 92 days) and teachers refused; formula neutralising; daily job (and Off); ERP API (JSON, CSV, bad date, unknown branch, export, list, events, unknown resources).
- Jest `kemFinanceExport`: preview, export and download link, empty period, server error, hidden without access.
