# F4.10 — Exams and hall tickets

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-06)

## Set-up

| Object                     | What it holds                                                                                                                                                                                                                                   |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exam**                   | Branch, exam code (unique, used in hall ticket numbers), type (Term, Final, Mock, Entrance, Competitive), dates, instructions for candidates, minimum attendance (empty = the branch's attendance threshold), withhold for overdue fees, status |
| **Exam Paper**             | One per class: date, start time, duration, maximum and pass marks, weight in the class grade; marks status (Not Entered, Draft, Published) and the gradebook assessment                                                                         |
| **Exam Candidate**         | Hall ticket number (`<exam code>-0001`), learner, status (Registered, Eligible, Withheld, Ticket Issued), withheld reason, override reason, attendance and overdue amount at the check, room and seat                                           |
| **Exam Mark** (MK-0000001) | A candidate's marks or absence in a paper                                                                                                                                                                                                       |

Administrators, branch managers and academic coordinators create an exam (**New exam**) and its papers (**Add paper**, one per class) on the desk.

Exam status runs Draft → Scheduled (candidates registered) → Hall Tickets Issued → Results Published (all papers published); Cancelled stops everything.

## Exam desk (`kemExamDesk`)

On each **Branch** page (no separate tab: the org has reached its custom tab limit), for the chosen exam of the branch: counts (papers, registered, eligible, withheld, tickets issued), the papers, the candidates, and four steps.

1. **Register candidates** — every learner enrolled in the papers' classes, once each, numbered in name order. Re-running adds only new learners.
2. **Check eligibility** — for candidates without a ticket: the lowest attendance across the exam's classes against the minimum, and, if the exam says so, overdue invoices. Each is Eligible or Withheld with the reason. Staff with **KEM Eligibility Override** can **Allow** a withheld candidate with a reason (kept on later checks).
3. **Allocate seats** — eligible candidates, in hall ticket order, filled into the chosen rooms of the branch by capacity (`Hall A-01`, …). Refused if the rooms are too small.
4. **Issue hall tickets** — eligible, seated candidates get a **hall ticket PDF** (candidate, date of birth, room and seat, the papers of their classes with dates and times, instructions, signature lines) filed on the candidate and shown in the family's portal documents; the fee payer gets the _Hall Ticket Issued_ message. Families of withheld candidates get _Hall Ticket Withheld_ with the reason, once.

**Marks:** per paper, **Enter marks** opens a sheet of the class's candidates (marks or absent; checked against the maximum), **Save marks**, then **Publish to gradebook**: a published **Exam** assessment is created in the class (maximum, weight, date) with each candidate's result, grades are recalculated, the paper's marks are locked, and when the last paper is published the exam becomes Results Published.

## Access

| Who                                                    | Can                                                                                                                              |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Administrators, branch managers, academic coordinators | Everything above; allowing withheld candidates needs KEM Eligibility Override                                                    |
| Teachers                                               | Read exams; enter marks (publishing follows the gradebook rule: the class teacher or someone with edit access to the assessment) |
| Families (portal)                                      | Their learners' hall tickets                                                                                                     |
