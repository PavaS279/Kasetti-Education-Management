# F4.6 — Agentforce: KEM Staff Assistant

**Status:** ✅ Built · ✅ Deployed · ✅ Unit tested · ✅ End-to-end checked (2026-10-06, actions; conversation in Lightning not yet tried by staff)

An **Agentforce employee agent**, _KEM Staff Assistant_, lets staff ask in plain language from the Agentforce panel in Lightning. It uses one topic, **Kasetti Education**, with five actions backed by Kasetti Apex. The agent never sends messages or changes records: drafts are returned to the conversation, and the topic instructions tell it to say so.

## Actions

| Action (GenAiFunction)             | Apex                  | What it does                                                                                                      |
| ---------------------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Answer a KEM Policy Question       | `AgentPolicyAnswer`   | Policy Q&A from the knowledge base with sources and a confidence flag (as [F4.5](F4.2-F4.5-ai-assistants.md))     |
| Summarise a KEM Learner's Progress | `AgentLearnerSummary` | Progress summary for a learner named in the conversation                                                          |
| Draft a KEM Enquiry Reply          | `AgentEnquiryDraft`   | Draft reply to an open enquiry, with an optional counsellor note; not sent                                        |
| Brief Me on a KEM Branch           | `AgentBranchBrief`    | Branch daily brief by name, code (for example `demo-01`) or Id                                                    |
| List KEM Learners at Risk          | `AgentAtRiskLearners` | Learners flagged by the retention score (all branches or one; High, Medium or All), up to 15 lines; no model call |

Names are resolved by `AgentSupport.resolve` **as the user**: one match is used; an exact name wins over partial matches; several matches come back as a list for the agent to ask "which one?"; no match says so. Errors are returned as readable text (for example "You do not have access to the AI assistants (KEM AI User)").

## Controls and measurement

- Actions run as the person chatting: sharing, field access, **KEM AI User** and the AI switches all apply.
- AI calls from actions are logged with channel **Agentforce** (outcome Not Applicable, as the answer goes straight to the conversation) and counted in the AI console. Logs are held until the end of the action, so an agent can send several requests at once.
- The topic instructions require the policy action for any policy question, sources after the answer, no figures that are not in the action's text, and the "draft, not sent" reminder.

The topic can also be added to another agent (for example Agentforce (Default)) in Agent Builder.

## Using it

Staff with KEM AI User and an Agentforce licence open the Agentforce panel in the Kasetti app, choose **KEM Staff Assistant** and ask, for example:

- "How many days do families have to pay an invoice?"
- "How is Ananya Sharma doing?"
- "Draft a reply to Demo Learner D2 and offer a trial class on Saturday."
- "How is branch DEMO-01 doing?"
- "Which learners are at high risk of leaving?"
