# KTEdutech — seeded data

Realistic operating data for the **KTEdutech** app (2026-10-06), created through the app's own services so every record follows the same rules as real use: prices and tax from the price book, seat control, fee lines, invoices numbered per centre, receipts, PDFs, notices, attendance rates, grades and risk scores.

- Re-create or extend it with `scripts/seed/seed.sh` (all stages) or `scripts/seed/seed.sh 05 06` (chosen stages). Every stage is idempotent and production-safe (additive only).
- Families are generated by `scripts/seed/families.py` (deterministic) into `scripts/seed/families.json`.
- Records carry hidden external ids for clean-up: `KT-FAM-…` (people), `KT-CRS-…` (courses), `KT-PRC-…` (prices), `KT-RM-…` (rooms), `KT-BR-…` (centres), `KT-AS-…` (assessments), `KT-ENQ-…` (enquiries), class section numbers `KT-…`.
- Emails use the reserved `example.com` domain, so nothing can reach a real inbox even when email delivery is switched on. Phone numbers are stored only (no SMS integration).
